# Minecraft 伺服器管理器使用手冊

## 系統需求

- Windows 11 21H2 以上，64 位元。
- Java：依 Minecraft 版本自動選用已安裝的相符版本；缺少時請至「管理 Java」手動安裝。
- 不需另裝 .NET。
- 網路：直接連線，不使用系統代理設定。

## 取得與啟動

下載 `MinecraftServerManager.exe`，按兩下即可啟動。

> [!NOTE]
> 首次啟動選一個資料夾，程式在其中建立 `servers` 存放伺服器（可於「管理伺服器」→「修改路徑」變更）。

> [!TIP]
> 表格：點表頭排序，拖曳分隔線或 Alt+←／→ 調欄寬，按兩下分隔線自動對齊。
>
> 快速鍵：F5 重新整理、Ctrl+F 搜尋、Delete 刪除選取項目、Enter 等同按兩下、Esc 關閉對話視窗。

## 功能操作

### 1. 建立伺服器

1. 選「建立伺服器」，輸入名稱。
2. 選載入器（建議 Paper；另有 Fabric、Quilt、Forge、NeoForge）與 Minecraft 版本。
3. Java 與記憶體：
   - 程式自動選用已安裝且主版本相符的 Java；找不到時會停止建立，請於「管理 Java」指定或以 winget 安裝。
   - 最大記憶體必填（MB），最小可留空。
   - 「JVM 參數設定...」可勾選建議參數或輸入自訂參數；可執行外部命令的參數會被排除。
4. 按「建立伺服器」即表示同意 Minecraft EULA（可按「閱讀 EULA」檢視）。
5. 下載核心並初始化，完成後跳到管理頁。Paper 外掛放入 `plugins/`。

### 2. 管理伺服器

選取伺服器後用下方按鈕或右鍵選單操作。

- **偵測現有伺服器**：掃描存放路徑，納入尚未登錄的伺服器。
- **修改路徑**：重選存放資料夾。
  - 有伺服器執行時無法修改。
  - 原路徑有資料時可選「遷移資料」（新路徑須為空）或「僅改設定」。
  - 新路徑於重新啟動程式後完整套用。
- **啟動**：
  - 可同時啟動多台。
  - 與執行中伺服器的連接埠相同時無法啟動。
  - 缺少核心檔案時停用啟動並標示缺漏項目。
- **停止**：送出 `stop` 並等待；超過 60 秒詢問「繼續等待」或「強制終止」。
- **關閉程式**：有伺服器執行時會詢問，確認後全部停止才結束。
- **名單管理**：管理員、白名單、封鎖玩家、封鎖 IP。
- **設定**：編輯 `server.properties`，數值會驗證。
- **記憶體設定**（右鍵）：最大值超過實體記憶體時自動調降。
- **備份**：需先設定備份資料夾與停止伺服器；超出保留上限時刪除最舊備份。
- **還原**：選備份點還原，保留現有的 `logs/` 與 `crash-reports/`；失敗自動回復。
- **刪除**：執行中不可刪除；可選擇一併刪除備份。

### 3. 監控視窗

啟動伺服器、在清單按兩下（或 Enter）或按「監控」開啟，每台一個。

- 顯示狀態、線上玩家、記憶體與運作時間；就緒時通知連線位址。
- 底部輸入指令按 Enter 送出；方向鍵上下瀏覽已送出的指令。
- 可自動捲動、清除或複製紀錄；點玩家名稱可複製。
- 「強制終止」立即結束行程。

### 4. 模組管理

- **本地模組**：
  - 勾選「啟用」切換啟用／停用；可多選後批次切換。
  - 「匯入模組」加入模組檔；右鍵可複製資訊、在資料夾中顯示或刪除。
  - 「檢查更新」找出相容最新版並補上必要相依；無法更新者列出原因。
  - 可匯出 `.txt`、`.json`、`.html`、`.xlsx`。
- **線上瀏覽**：
  - 輸入關鍵字搜尋相容模組；選版本時自動列入必要相依。
  - 「檢視安裝清單」後按「開始安裝」；只從 Modrinth 官方下載並驗證雜湊。

### 5. 匯入伺服器

「匯入伺服器」可選資料夾或 ZIP。

- **複製**（預設）：保留來源。
- **遷移**：全部成功後才移除來源。
- 存放目錄已有同名非空資料夾，或來源為磁碟根目錄、存放目錄或其上層時無法匯入。

### 6. 關於與設定

- **更新**：可自動或手動檢查；下載以 SHA-256 驗證（只確認檔案完整；要確認來源可用 `gh attestation verify MinecraftServerManager.exe --repo Colin955023/MinecraftServerManager`）。
- **外觀**：主題（系統、淺色、深色）與強調色。
- **備份**：「啟動伺服器前自動備份」；每台伺服器保留份數（1～100，預設 10）。
- **視窗**：「重設為預設大小」還原主視窗大小。
- **還原預設**：還原所有偏好設定。

## 常見問題

### 伺服器啟動失敗或立刻當機
- Java 主版本須與官方要求完全一致（例如 1.20.5 以上需要 Java 21），不符時會阻擋啟動；請至「建立伺服器」→「管理 Java」安裝。
- 在監控視窗檢視錯誤訊息，確認模組相依與記憶體設定。

### 程式異常結束後，伺服器仍在背景執行
下次啟動會提示「偵測到遺留的伺服器行程」：
- **強制終止**：結束這些行程。
- **暫不處理**：保留行程；結束前該伺服器無法再次啟動。

### 啟動時出現 Windows SmartScreen
本軟體未購買商業憑證。點「其他資訊」→「仍要執行」。

### 回報問題
至 [GitHub Issues](https://github.com/Colin955023/MinecraftServerManager/issues) 提出，附上 Windows 版本、操作步驟與記錄檔（`%LOCALAPPDATA%\Programs\MinecraftServerManager\Logs\`）。
