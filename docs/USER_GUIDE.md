# Minecraft 伺服器管理器使用手冊

本手冊提供 Minecraft 伺服器管理器的完整操作流程、功能指南與常見問題排除說明。

## 系統需求

- **作業系統**：Windows 10／11（64 位元）
- **Java 環境**：執行 Minecraft 伺服器所需的 Java Runtime（Java 8 至 Java 21+）
  - 軟體內建自動掃描本機已安裝之 Java 功能，亦可手動瀏覽指定 `java.exe`
- **.NET 執行環境**：
  - **獨立自包含版（Self-contained）**：內建完整 .NET 10 Runtime 與依賴項，隨點即開，無需額外安裝任何執行環境
  - **框架相依版（Framework-dependent）**：需先安裝微軟官方 [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/)，體積極小

## 取得與啟動

可執行檔位於專案發布目錄 `output/`：

| 檔案名稱 | 版本類型 | 檔案大小 | 適用情境與說明 |
|---|---|---|---|
| **`MinecraftServerManager-self-contained.exe`** | 獨立自包含版 | 約 62 MB | **強烈推薦**，適合所有使用者，內建完整 .NET 10 執行環境與官方單檔壓縮，下載即可直接執行 |
| **`MinecraftServerManager-framework-dependent.exe`** | 框架相依版 | 約 1.6 MB | 適合進階使用者，電腦必須預先安裝 .NET 10 Desktop Runtime (x64) |

> [!TIP]
> 若執行 `MinecraftServerManager-framework-dependent.exe` 時系統提示需要安裝 .NET 執行階段，代表您的電腦尚未安裝 .NET 10 Desktop Runtime。此時請至微軟官網下載安裝，或直接改用 **`MinecraftServerManager-self-contained.exe`** 即可順暢運作。

雙擊對應的可執行檔即可啟動主程式。

## 功能操作指南

### 1. 建立全新伺服器

1. 點選左側導覽列的「建立新伺服器」。
2. **基本資訊**：輸入自訂的伺服器名稱，系統會自動規劃存放目錄。
3. **載入器與版本**：
   - 支援 Vanilla（原版）、Fabric、Quilt、Forge、NeoForge。
   - 選擇目標 Minecraft 版本與對應的載入器版本。
4. **Java 與記憶體設定**：
   - 系統會依選定的 Minecraft 版本自動選取合適的 Java，若需變更可點擊「瀏覽」選取指定路徑。
   - 拖動記憶體拉桿設定最大配置量，系統會依 Java 版本智慧配置 JVM 垃圾回收優化參數（G1GC／ZGC）。
5. **使用者授權合約（EULA）**：勾選「我同意 Minecraft EULA」。
6. 點擊「建立伺服器」，程式將自動下載所需核心檔案並完成初始化安裝。

### 2. 伺服器日常管理

在左側「管理伺服器」頁面，可檢視所有已建立的伺服器卡片與目前運作狀態：

- **啟動伺服器**：點擊卡片上的「啟動」按鈕，伺服器將於獨立監控視窗中啟動。
- **開啟資料夾**：點擊「開啟資料夾」，直接在檔案總管中開啟該伺服器的根目錄。
- **屬性設定**：點擊「屬性設定」開啟 `server.properties` 編輯視窗，修改遊戲難度、PVP、最大玩家數等參數（內建版本樂觀鎖保護，防止並行儲存衝突）。
- **立即備份**：點擊「備份」，系統將自動封裝為 ZIP 備份檔，並自動保留最新 10 份備份。
- **還原備份**：點擊「還原」，選擇歷史備份點進行交易式安全還原。
- **刪除伺服器**：點擊「刪除」並確認後，安全移除伺服器目錄。

### 3. 獨立主控台即時監控

伺服器啟動後，將開啟專屬的即時監控視窗：

- **即時狀態**：頂部顯示即時伺服器運行狀態與在線玩家數量（由系統自動精確解析加入／退出事件）。
- **高效能日誌**：採用 50ms 微批次聚合技術，杜絕大量輸出時的介面凍結，並自動過濾終端 ANSI 色碼。
- **指令發送**：在底部輸入框鍵入 Minecraft 指令（例如 `op <玩家名稱>` 或 `say <公告>`），按 Enter 即可發送至伺服器 stdin。
- **停止伺服器**：
  - **停止**：優先發送優雅停止指令（`stop`），等待伺服器安全儲存世界地圖後關閉。
  - **強制終止**：若伺服器未於時限內關閉，可執行強制終止以清理殘餘程序。

### 4. 模組管理與 Modrinth 線上安裝

在「模組管理」頁面選擇欲管理的模組伺服器：

- **本地模組管理**：
  - 自動列出 `mods` 資料夾中的所有模組與狀態，支援 Windows 原生多選（Ctrl 多選、Shift 連選）。
  - 雙擊模組項目或點擊操作按鈕即可智慧切換「啟用」與「停用」（透過標準 `.jar` 與 `.jar.disabled` 切換，並自動處理衝突備份）。
  - 支援右鍵快捷選單：切換啟用狀態、複製模組資訊、在檔案總管中顯示與刪除模組。
  - 選取 2 個以上模組時自動啟用「批次切換」功能；「檢查更新」僅針對已選取之模組執行。
  - 提供多格式匯出功能，可將模組清單匯出為純文字檔（.txt）、JSON（.json）、HTML（.html）或 Excel（.xlsx）報表，匯出完成後可一鍵開啟檢視。
- **Modrinth 線上搜尋與安裝**：
  - 頂部明確提示目前伺服器的相容條件（Minecraft 版本與載入器類型），輸入關鍵字即時搜尋相容模組。
  - 點擊「下載安裝」，系統將非同步下載並自動比對 SHA-512／SHA-1 雜湊值，驗證通過後直接部署至 `mods` 目錄。

### 5. 交易式備份與安全還原

- **自動輪替原則**：每次建立備份均會記錄時間戳記，系統維持最多 10 份最新備份，逾期檔案自動安全清理。
- **交易式還原保證**：還原過程先於隔離暫存區解壓縮並校驗路徑安全性；在覆蓋前自動建立還原快照（Rollback Snapshot），若還原中途遭遇異常，系統會自動回復至原本狀態，防止世界資料損壞。

### 6. 外部伺服器匯入與軟體更新

- **匯入伺服器**：點選導覽列的「匯入伺服器」，可選取本機現有的伺服器資料夾或 ZIP 壓縮檔，安全匯入至管理器統一維護。
- **檢查更新**：於「設定」或「關於」頁面點擊「檢查更新」，程式會連線至 GitHub Releases 檢查有無新版本發布。

## 常見問題與故障排除

### 1. 啟動框架相依版時提示缺少 .NET 執行環境
若執行 `output/MinecraftServerManager-framework-dependent.exe` 出現提示視窗，請前往微軟官方網站下載並安裝 [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/)，或直接改用內建完整環境的 `output/MinecraftServerManager-self-contained.exe`。

### 2. 伺服器啟動失敗或瞬間崩潰
- 請檢查伺服器設定的 Java 版本是否與 Minecraft 版本相符（例如 Minecraft 1.20.5+ 需要 Java 21 以上）。
- 請至主控台視窗檢視崩潰日誌（Crash Report），確認是否因模組相依性缺失或記憶體配置超出實體限制所致。

### 3. 如何回報問題或建議
如遇程式異常，請至 [GitHub Issues](https://github.com/Colin955023/MinecraftServerManager/issues) 提出，並附上 Windows 版本、使用的版本類型、操作步驟與日誌檔案（位於 `%LOCALAPPDATA%\Programs\MinecraftServerManager\Logs\`）。
