# Minecraft 伺服器管理器使用手冊

## 系統需求

- Windows 11 21H2（10.0.22000）以上，64 位元。
- Java：執行伺服器所需（Java 8～21+）。程式可自動掃描本機 Java，或手動指定 `java.exe`。
- 已內建 .NET 10 與 WinUI 3 執行階段，不需另外安裝。

## 取得與啟動

主程式是單一檔案 `MinecraftServerManager.exe`（約 31 MB），按兩下即可啟動。

> [!NOTE]
> 首次啟動會請你選一個資料夾，程式在其中建立 `servers` 子資料夾存放所有伺服器（所選資料夾已名為 `servers` 則直接使用）；未選擇時會詢問是否結束程式，選「否」則重新選取。之後可在「管理伺服器」頂部按「修改路徑」變更。

> [!TIP]
> 重點按鈕預設跟隨 Windows 個人化強調色，也可在「關於與設定」自訂。所有子視窗開啟時置中於主視窗，可縮放。表格可拖曳表頭分隔線調欄寬、按兩下自動對齊最寬項目、點表頭排序（容量、數量、日期依實際數值排序）。

## 功能操作

### 1. 建立伺服器

1. 左側選「建立伺服器」，輸入伺服器名稱。
2. 選載入器（建議 Paper；另支援 Fabric、Quilt、Forge、NeoForge）與 Minecraft 版本，版本清單由官方 API 動態查詢。
3. Java 與記憶體：
   - 依載入器與版本自動查詢官方 Java 需求並選用合適的 Java。
   - 「管理 Java」可檢視本機 Java、自動偵測最佳版本、手動指定，或用 winget 安裝（Java 8 為 Oracle JRE，其餘為 Microsoft OpenJDK；安裝前會先檢查本機是否已有可用版本）。
   - 在輸入框填入記憶體（單位 MB）：最大記憶體必填，最小記憶體可留空由 Java 決定。程式依 Java 版本建議 GC 參數（Java 21 以上為 ZGC，其餘為 G1GC）。「JVM 參數設定...」可勾選建議參數或輸入自訂參數。
   - Forge／NeoForge 的 GC、記憶體與自訂參數會自動寫入 `user_jvm_args.txt`，批次檔啟動時自動注入 `JAVA_HOME` 與 `PATH`。
4. 閱讀並同意 Minecraft EULA；按「建立伺服器」即表示同意。
5. 程式下載核心並開啟初始化視窗產生設定與世界，就緒後 2 秒自動跳到管理頁。Paper 外掛放入伺服器根目錄的 `plugins/`。

### 2. 伺服器日常管理

「管理伺服器」頁列出所有伺服器與狀態。頂部「偵測現有伺服器」會掃描存放路徑並納入尚未登錄的伺服器，「手動新增」跳到建立頁，「重新整理」重新讀取清單。選取伺服器後用下方按鈕操作；在清單上按右鍵可「修改記憶體設定」、「重新偵測伺服器」、「開啟備份資料夾」、「修改備份路徑」。

- **修改存放路徑**：按「修改路徑」重選資料夾（新路徑為其下 `servers`）。
  - 有伺服器執行時無法修改。
  - 與原路徑相同則不動作；位於原路徑之內則只改設定、資料留在原處。
  - 原路徑已有資料時會詢問：「是，遷移資料」（新路徑須為空，含 `servers.json` 完整搬移；跨磁碟失敗會清理並保留原檔）、「否，僅改設定」、「取消」。
  - 完成後程式自動重新啟動。
- **狀態與目錄大小**：背景計算目錄大小（不含備份目錄）；缺少核心必要檔案時以警示色標示缺漏項目並停用啟動。
- **啟動／停止**：按「啟動」。
  - 可同時啟動多台伺服器，每台有各自的監控視窗。
  - 啟動前會檢查是否與執行中伺服器使用相同連接埠（`server-port`，未設定視為 25565），相同則無法啟動，請先到「設定」修改其中一台。
  - 開啟「啟動前自動備份」時，啟動前先備份；無備份資料夾或備份失敗時會詢問是否仍要啟動。
  - 按「停止」送出 `stop` 並顯示「停止中」，等待世界儲存；超過 60 秒會詢問「繼續等待」或「強制終止」（強制終止可能遺失尚未寫入的世界資料），不會自動強制終止。
- **關閉程式**：有伺服器執行時關閉主視窗，會列出執行中的伺服器並詢問「停止伺服器並結束」；確認後顯示進度，全部停止才結束，選「取消」則不關閉。
- **名單管理**：管理員（`ops.json`，OP 1～4 級與略過人數限制）、白名單（`whitelist.json`）、玩家封鎖（`banned-players.json`）、IP 封鎖（`banned-ips.json`）；核取方塊按一下即切換，並讀取 `usercache.json` 關聯玩家 UUID 與名稱。
- **設定**：編輯 `server.properties`（連接埠 1～65534、IP、列舉值等會驗證；他處同時修改時會偵測衝突）。
- **記憶體設定**（右鍵選單）：輸入最大／最小記憶體（MB，最小可留空）；最大值超過系統實體記憶體時自動調降並提示。
- **開啟資料夾**：在檔案總管開啟伺服器根目錄。
- **備份**：需先為伺服器設定外部備份資料夾（首次備份會請你選擇，之後可用右鍵「修改備份路徑」變更）；封裝為 ZIP，超過保留份數（預設 10，可在「關於與設定」調整）自動刪除最舊的；執行中的伺服器需先停止才能備份。
- **還原**：選歷史備份點還原（自動保留伺服器現場的 `logs/` 與 `crash-reports/`，中途失敗自動回復）。
- **刪除**：確認後移除伺服器；執行中不可刪除；若有管理的備份，會詢問是否一併刪除。

### 3. 監控視窗

啟動伺服器、在清單按兩下或按「監控」即開啟，每台伺服器一個。

- 顯示狀態（啟動中、已就緒）與線上玩家數，由輸出自動解析；就緒時右上角通知（含連線位址與連接埠）。
- 大量輸出不會凍結介面，自動過濾色碼。
- 底部輸入 Minecraft 指令（如 `op <玩家>`、`say <公告>`）按 Enter 或「傳送指令」送出；方向鍵上下可瀏覽這次開啟監控視窗後送出過的指令，回到最下方時還原尚未送出的草稿。
- 開啟時會載入 `logs/latest.log` 尾端的既有內容；可切換「自動捲動」、「清除紀錄」、「複製全部紀錄」，點線上玩家名稱可複製。
- 「停止」同上述平順停止流程；「強制終止」立即結束行程。

### 4. 模組管理

選擇模組伺服器後：

- **本地模組**：
  - 列出 `mods` 內模組與狀態，Windows 自然排序，可輸入關鍵字篩選，Ctrl／Shift 多選或「全選」，點空白處取消選取。
  - 勾選每列的「啟用」核取方塊切換啟用／停用（`.jar` ↔ `.jar.disabled`，自動處理衝突備份）。
  - 「匯入模組」加入本機的模組檔；「開啟模組資料夾」在檔案總管開啟 `mods`。
  - 右鍵：複製模組資訊、在資料夾中顯示、刪除模組。
  - 選 2 個以上可批次切換；選任一模組可「檢查更新」：用 FlexVersion 找相容最新版，缺少的必要相依模組一併列入（已安裝的視為已滿足），與已安裝模組衝突或找不到相容相依者不更新並列出原因。
  - 可匯出 `.txt`、`.json`、`.html`、`.xlsx`。
- **Modrinth 線上搜尋與安裝**：
  - 頂部顯示伺服器的相容條件（Minecraft 版本與載入器），輸入關鍵字搜尋相容模組。
  - 選版本時自動遞迴解析必要相依並提示一併排入。
  - 「檢視安裝清單」開啟待安裝／更新清單，可清空或「開始安裝」；僅允許自官方 Modrinth CDN（`cdn.modrinth.com`）下載，並強制以 SHA-512／SHA-1 驗證後放入 `mods`。

### 5. 匯入伺服器

導覽列「匯入伺服器」可選資料夾或 ZIP（Vanilla、Paper 與各載入器），背景匯入並自動檢查核心、載入器與設定。

- **複製**（預設）：保留來源。
- **遷移**：開始前會確認；匯入、驗證、寫入設定全部成功後才移除來源資料夾或 `.zip`，中途取消或失敗絕不刪除來源。
- 來源已在伺服器根目錄內時以原地納管處理，不刪除。

### 6. 關於與設定

- 版本、技術堆疊、授權（GPLv3）與 GitHub 連結。
- **更新**：勾選「自動檢查更新」於啟動時比對版本；「檢查更新」立即檢查，下載以官方 SHA-256 digest 驗證。
- **外觀**：主題模式可選「依照系統設定」、「淺色」、「深色」；預設用 Windows 強調色，可「挑選自訂顏色」或「重設為系統強調色」。
- **備份設定**：「啟動伺服器前自動備份」（預設關閉）；每台伺服器保留的備份份數（1～100，預設 10）。
- **視窗**：顯示目前螢幕解析度與視窗大小；「重設為預設大小」還原主視窗大小。
- **還原預設**：頁面底部的「還原預設」經確認後將所有偏好設定還原為預設值。

## 常見問題

### 伺服器啟動失敗或立刻當機
- 確認 Java 版本符合 Minecraft 版本（例如 1.20.5 以上需要 Java 21 以上）。
- 在監控視窗檢視當機報告，確認是否缺少模組相依或記憶體超出實體限制。

### 程式異常結束後，伺服器仍在背景執行
程式閃退或被強制結束時，Java 行程可能繼續執行而無法控制。下次啟動偵測到時會跳出「偵測到遺留的伺服器行程」：
- **強制終止**：立即結束這些行程。
- **暫不處理**：保留行程；行程結束前該伺服器無法再次啟動。

### 啟動時出現 Windows SmartScreen
本軟體為免費開源專案，未購買商業憑證。出現「Windows 已保護您的電腦」時，點「其他資訊」→「仍要執行」。程式更新皆內建 SHA-256 驗證。

### 回報問題
至 [GitHub Issues](https://github.com/Colin955023/MinecraftServerManager/issues) 提出，附上 Windows 版本、操作步驟與記錄檔（`%LOCALAPPDATA%\Programs\MinecraftServerManager\Logs\`）。
