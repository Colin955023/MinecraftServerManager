Minecraft 伺服器管理器

針對 Windows 11 本機運作設計的桌面管理程式。整合官方目錄與載入器下載、動態 Java 版本配對、獨立即時主控台視窗、Modrinth 相依解析與可回復式備份還原。下載單一執行檔即可執行，不需額外安裝 .NET Desktop Runtime。

主程式畫面一覽

點選任意縮圖可開啟完整實機畫面。以下均由 Windows 11 實機執行擷取。

建立新伺服器

下載與初始化 Paper、Fabric、Quilt、Forge 與 NeoForge，自動比對官方 Java 版本要求。

管理伺服器與完整性檢查

啟動前確認核心檔案與連接埠狀態，並整合目錄遷移、快照式備份還原與遺留行程清理。

即時主控台與終端輸入

每台執行中伺服器各有獨立監控視窗，即時統計記憶體、線上人數與運作時間，啟動完成立即通知。

名單與權限管理

圖形化調整管理員權限（OP Level 1～4）、白名單與玩家或 IP 封鎖項目，無須手動編輯 JSON。

模組相依性與清單匯出

掃描與識別模組來源，支援批次停用、Modrinth 前置相依帶入，以及匯出純文字、JSON、HTML 與 .xlsx。

外觀主題與備份策略

可隨系統或強制切換深淺色、調整強調色，並設定自動備份保留數量（1～100 份）與更新規則。

技術規格、支援載入器與檔案位置

從版本匹配、安全啟動到資料儲存的完整設計細節。

  • 動態 Java 版本配對

    嚴格依據 Mojang 官方 JSON 中的 javaVersion.majorVersion（與快取 java_version.major）選擇 Java，未標註之舊版為 jre-legacy (Java 8)；並過濾 javapath、檢查 PE 64 位元格式，無相容版本時可透過 winget 安裝。

  • 安全啟動與行程偵測

    統一產生含絕對路徑 Java 的 start_server.bat，並主動排除 -XX:OnError、-XX:OnOutOfMemoryError、-agentpath、-agentlib 與 -Xbootclasspath 等參數；程式會登記執行中 PID 與時間戳以便重開後清理遺留行程。

  • 目錄防護與可回復還原

    所有寫入與解壓均強制檢查目錄邊界並攔截符號連結或壓縮炸彈。還原備份前會先建立快照並刻意暫存 logs/ 與 crash-reports/，還原完成再合併移回；遇錯即刻從快照回復。

  • Modrinth 來源驗證與更新

    僅從 Modrinth 官方公開 HTTPS CDN 下載並驗證檔案雜湊；自動展開相依前置套件並於版本衝突時保留既有檔案，離線時可降級讀取先前版本快取。

快速上手四步驟

  1. 自 GitHub Releases 下載 MinecraftServerManager.exe（v2.1.1 舊版名為 MinecraftServerManager-self-contained.exe），Windows 11 x64 可直接執行。
  2. 首次啟動指定伺服器根目錄，程式會在其中建立或沿用 servers\ 子目錄與 servers.json。
  3. 於「建立伺服器」選擇載入器（建議 Paper）與版本後點擊建立（操作即同意 Minecraft EULA），依提示完成首次初始化。
  4. 於「管理伺服器」點選伺服器以操作啟動、設定與名單，按兩下列表可開啟主控台；備份前先停止伺服器並指定外部備份目錄。

本機設定與快取存放位置

資料項目 預設實體位置 儲存與防損保護
使用者設定檔 %LOCALAPPDATA%\Programs\MinecraftServerManager\user_settings.json 原子寫入；檔案損毀時自動另存 .bad 後重建預設
伺服器清單檔 <所選資料夾>\servers\servers.json 記錄已建立或匯入伺服器與各自外部備份目錄，具原子寫入保護
執行中伺服器清單 %LOCALAPPDATA%\Programs\MinecraftServerManager\running_servers.json 紀錄執行中伺服器 PID 與啟動時間，供重啟時辨識遺留行程

程式日誌與工作階段標記 %LOCALAPPDATA%\Programs\MinecraftServerManager\Logs\ 日誌輪替紀錄並透過 session.marker 偵測先前是否異常結束

常見問題

執行主程式需要預先安裝 .NET Desktop Runtime 或 Visual Studio 嗎？

不需要。發布版本 MinecraftServerManager.exe 為針對 Windows 11 x64（21H2 / Build 22000 以上）裁剪編譯之單一自包含執行檔，下載後點兩下即可直接執行。

為什麼限定 Windows 11，且啟動伺服器時如何決定 Java 版本？

介面採用原生 WinUI 3 與 Windows App SDK 建置（TargetPlatformMinVersion=10.0.22000.0）。Java 主要版本完全依據 Mojang 官方 JSON 的 javaVersion.majorVersion（與快取 java_version.major）動態選擇（未標註舊版為 jre-legacy Java 8）；找不到合適 64 位元 Java 時可在「管理 Java」視窗呼叫 winget 安裝。

還原伺服器備份時會不會覆蓋掉先前的崩潰日誌或除錯紀錄？

不會。進行還原前程式會先解壓檢查壓縮檔安全並建立目前目錄快照，同時暫存現有的 logs/ 與 crash-reports/，還原完成後再合併移回。若中途發生檔案鎖定或寫入失敗，會自動從快照復原。

如果應用程式意外關閉，背景執行中的伺服器會怎樣？

running_servers.json 會記錄每台執行中伺服器的 PID 與啟動時間。下次啟動管理器時，程式會比對該清單與系統行程狀態偵測遺留行程，協助您直接處理而避免連接埠衝突或存檔損壞。

如何將伺服器搬移至其他磁碟，或指定額外的外部備份資料夾？

在所有伺服器皆停止時，進入「管理伺服器」點選「修改路徑」挑選新資料夾（程式會在其下使用 servers\）；若原路徑已有伺服器，可選擇「是，遷移資料（新路徑須為空資料夾）」、「否，僅改設定」或「取消」，完成後自動重啟套用。備份路徑則對該伺服器列按右鍵 →「修改備份路徑」。
